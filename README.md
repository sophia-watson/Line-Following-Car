# Line-Following-Car
The goal of this project was to design an autonomous robotic car capable of following a line using only analog electronics.
The car was designed using a fully analog control system consisting of a latch switch, sensor circuits, comparators, and motor drivers. A 555 timer configured as a latch circuit was used to initiate operation using a push-button. Once activated, the system supplied power to the rest of the circuit and maintained operation without requiring continuous input.
The car uses two optical sensing circuits to detect contrast between the black line and the surrounding surface. These signals are fed into an LM393 comparator, which determines whether each sensor is detecting the line. Based on the comparator outputs, the motors are controlled independently, allowing the car to steer by adjusting the speed of each wheel.
This project successfully demonstrated the design and implementation of a fully analog line-following car. By integrating a 555 timer latch circuit, optical sensors, an LM393 comparator, and transistor-based motor control, the car was able to operate autonomously and follow a curved path. While challenges such as sensor noise and motor imbalance were encountered, they were resolved through calibration and testing. Overall, the project provided valuable experience in analog circuit design and highlighted the importance of signal conditioning and troubleshooting in engineering systems.
